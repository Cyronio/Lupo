# Lupo
A simple 2D pixel puzzle platformer made in 3 days for GMTK Game Jam 2025.

It can be played here: https://cyrotronic.itch.io/lupo

<img src="https://github.com/Cyronio/Lupo/blob/main/Screenshots/Lupo2.jpg">

# Controls
Arrow Keys or WASD for moving

Space or Return for jumping
